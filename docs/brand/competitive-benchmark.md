## 0. 벤치마킹 원칙 (상업적 안전)

| 해도 됨 | 하지 말 것 |
|---------|------------|
| 시장에 알려진 **기능 유형**을 요구사항으로 정리 | 타사 UI/카피/아이콘/플로우 스크린샷 복제 |
| 공개 스펙·문서에 나온 능력 수준을 ●/◐/○로 평가 | 비공개 자료·유출 데모·계약 가격 무단 인용 |
| **자체 설계**로 동등·우수 기능 구현 | 상표명·로고를 제품 UI에 무단 사용 |
| “Signavio급 저장소”처럼 **카테고리 비유** (영업 문장) | 경쟁사 문서 문구 그대로 제안서에 붙여넣기 |
| 오픈 표준(BPMN 2.0, OIDC, REST) 준수 | 독점 파일 포맷 역공학 |

**Procivio 제품 원칙 유지**  
> 실행 엔진(Camunda급) · 풀 마이닝(Celonis급) 내재화는 **비목표**.  
> **인터뷰 → 계층 구조 DB → 거버넌스 맵** 이 차별축.

## 3. 벤치 기능 상세 스펙 (구현 가능한 수준)

상업적으로 **자사 설계로 구현**할 때 쓸 요구사항 초안.  
(경쟁 UI 복제가 아닌 **결과물·수용 기준** 정의.)

### 3.1 P0 — 90일 차별화 본체

#### F-P0-01 LLM 인터뷰 모드 (Procivio Inquire)

| 항목 | 내용 |
|------|------|
| **사용자 가치** | 컨설턴트 없이 L1–L3 초안을 대화로 확보 |
| **동작** | 세션 시작 → 목표/범위/시작·종료 이벤트 질문 → 분기·예외·역할 질문 → 구조 초안 제안 |
| **산출** | `ProcessStructure` JSON (levels[], nodes[], edges[], open_questions[]) |
| **수용 기준** | 10턴 이내 최소 1개 L2 프로세스 + 3개 이상 활동 노드; 사용자는 문항 skip 가능 |
| **가드레일** | 환각 노드 표시·부분 적용·Undo; 토큰/키 캐스케이드(이미 구현) |
| **벤치 출처 유형** | AI discovery / 워크숍 대체 (기능 유형만) |

#### F-P0-02 레벨 택소노미 + Structure 트리

| 항목 | 내용 |
|------|------|
| **모델** | `level: 0..n` (기본 권장: L0 가치사슬, L1 프로세스 그룹, L2 프로세스, L3 활동) |
| **UI** | 좌측 트리(접기/펼치기) · 클릭 시 Canvas 포커스 · 맵 간 Call Activity 연결 표시 |
| **수용 기준** | 동일 version 내 레벨 이동·필터; 게시본에서 트리 읽기 전용 |
| **벤치** | ARIS/Signavio 아키텍처 저장소 **개념** (표기·UI 자체 설계) |

#### F-P0-03 구조 적용 diff

| 항목 | 내용 |
|------|------|
| **동작** | AI 제안 = add/remove/relabel/connect 목록 → 체크박스 부분 수락 → 그래프 반영 |
| **수용 기준** | 거절된 op는 히스토리에 남김; 체크아웃 보유자만 적용 |
| **벤치** | 코드리뷰식 패치 UX (Git/PR 은유, 타사 BPM UI 비복제) |
